# Changelog

All notable changes to Island will be documented in this file.

## [0.2.0] - 2026-07-26

### Added

- Windows Tauri v2 desktop shell with main library and floating island windows
- Local managed file imports with SHA-256 deduplication
- SQLite WAL storage, migrations, FTS5 search and integrity checks
- URL and text capture
- Inbox, recent items, favorites, trash, editing and system opening
- Database backup and portable JSON/CSV/file export
- Responsive light/dark UI, keyboard focus and reduced-motion support
- Frontend and Rust tests plus Windows CI
