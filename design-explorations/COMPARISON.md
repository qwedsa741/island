# Island 四套视觉方向对比

所有稿件使用相同资料、相同三栏结构和相同窗口尺寸 `1220×760`，方便只比较设计语言。

| 方向 | 核心印象 | 最突出的优势 | 主要风险 | 建议 |
|---|---|---|---|---|
| A 夜航档案馆 | 私密、专业、沉浸 | 深色工具外壳与暖纸阅读区形成明确品牌记忆 | 深色灰阶需要长期细调 | 首选 |
| B 纸墨研究所 | 温暖、知识、收藏 | 中文宋体标题与纸质档案感最适合长期知识沉淀 | 容易显得过于文艺，效率感略弱 | 次选 |
| C 瑞士索引系统 | 精确、理性、强识别 | 网格、编号和文字缩写彻底摆脱通用 SaaS 感 | 个性较强，学习成本最高 | 适合小众专业定位 |
| D Windows 原生工坊 | 熟悉、可靠、商业化 | 与 Windows 11 融合最好，实现风险最低 | 品牌辨识度最低 | 可作为交互行为基线 |

## 跨方案共同调整

- 文件类型改为单色文字缩写，不再使用多彩类型色块。
- 详情默认是阅读状态，不再把标题和备注永久显示为表单。
- 选中状态不依赖大面积高饱和填色。
- 主标题降低机械粗体感，辅助信息建立稳定基线。
- 阅读入口是详情区唯一主操作。
- Agent 不占据资料主线，只作为上下文能力出现。

## 推荐组合

正式实现建议以 A 为骨架：

- 主窗口采用夜航档案馆。
- 阅读纸张与长文排版吸收 B 的温度。
- 元数据和快捷键提示吸收 C 的精确性。
- 菜单、焦点和窗口行为遵循 D 的 Windows 原生规则。
